Contributor: Austint30; assembled and processed October/November 2026.

- [Coastal Cliff 02](https://polyhaven.com/a/coastal_cliff_02), Rob Tuytel.
- [Coastal Cliff 04](https://polyhaven.com/a/coastal_cliff_04), Rob Tuytel and Rico Cilliers.
- [Rock Face 01](https://polyhaven.com/a/rock_face_01), Dario Barresi.
- [Rock Face 02](https://polyhaven.com/a/rock_face_02), Dario Barresi and Rico Cilliers.
- [Rock 06](https://polyhaven.com/a/rock_06), Rob Tuytel: shared `rock_grain.normal.webp`,
  broad slopes removed and fine grain renormalized.

No generative model is used for these scan inputs. Original scan retrieval dates
and tool package versions were not retained. The supplied sources are the
reproducible input to `modtextures.py`; fallback resampling is implemented in
`tools/prepare_cliff_pack.py`.

Applies to `natural_*.webp`, `rock_grain.normal.webp`, the natural height reference,
and the scan-derived road-cut height reference described in
`cliff_references.NOTICE.md`, including optional higher-resolution variants.
