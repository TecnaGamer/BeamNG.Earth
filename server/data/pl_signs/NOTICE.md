# Polish road sign positions

Each record contains the source identifier, longitude, latitude, exact artwork code and clockwise face bearing from north (null when unavailable). The derived coordinates and classes are distributed separately from the game's software licence.

- **osm.json** — © OpenStreetMap contributors, [Open Database License 1.0](https://www.openstreetmap.org/copyright). Generated from the [BBBike Poland PBF](https://data.bbbike.org/osm/pbf/region/europe/poland.osm.pbf), published 19 November 2026 at 01:42 UTC. Input included 54,148 nodes carrying `traffic_sign`. The record ID is an OSM node ID.
- **mapillary.json** — sign detections from [Mapillary](https://www.mapillary.com/), imported from two contributor GeoJSON exports around Charzykowy and Chojnice (10 and 142 features; 145 observations with known Polish designs). IDs are Mapillary map feature IDs. This derived metadata is distributed under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/), following [Mapillary's guidance on publishing derived metadata](https://help.mapillary.com/hc/en-us/articles/115001777705-OpenStreetMap-compatibility).
- **wroclaw.json** — Gmina Wrocław, System Informacji Przestrzennej Wrocławia, [WIM_ZnakiDrogowe_View](https://gis.um.wroc.pl/portal_srv/rest/services/WIM_ZnakiDrogowe_View/MapServer), accessed 19 November 2026. Point layers 0, 2 and 3 were queried in EPSG:4326, with attributes OBJECTID, ZNAK, WARTOSC and DATA_WYN. The output retains installed records with a matching sign variant and uses the sign code and original object ID for traceability. These data have been filtered and reformatted for the game. The city is not responsible for the processing or further use. [Municipal reuse information](https://bip.um.wroc.pl/artykul/7/1/ponowne-wykorzystywanie-informacji-sektora-publicznego).
- **Territorial filter** — Główny Urząd Geodezji i Kartografii, Państwowy Rejestr Granic, [national boundary](https://ogcapi.geoportal.gov.pl/res/ims/maps/PRG/apiFeatures/collections/GranicaPanstwa/items?f=json&limit=1), accessed 19 November 2026. Used during import and retained as the original polygon edges in prg.npz for checking final sign positions in the game.

The sign faces are credited individually in the [Commons source manifest](../../../tools/sign_art/pl/sources.json). In particular, Polish sign C-9 by odder and its uniformly rasterised texture are licensed under [CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/). B-18-3.5t is marked CC0. Additional models record their Commons file page, credit, licence and checksum in ready.json.
