Where players are now

A country is listed once it has at least 5 players online; smaller counts are grouped as "other".

Anonymous: each report carries a random install id, the app version and system, whether the game is connected, and how many requests went to each map-data source. No names, accounts, positions or IP addresses are kept; the country is looked up from the address and the address is discarded. Players can turn reports off with BNE_TELEMETRY=off.
