# German Autobahn sign lettering and pictograms

Inputs of `tools/build_de_autobahn_atlas.py`, which draws them into the German Autobahn signs' own atlas
(`mod/beamng_earth/levels/beamng_earth/art/shapes/beamngEarth/de_autobahn/`, `server/data/de_sign_font.json`).

## Fonts

- `DINish-Medium.otf`, `DINishCondensed-Medium.otf`: DINish v4.007 (https://github.com/playbeing/dinish), a DIN 1451
  Mittelschrift / Engschrift lookalike derived from D-DIN, with the post-1981 glyph forms used on current German signs.
  Copyright 2021 The DINish Project Authors. SIL Open Font License 1.1, no Reserved Font Name (`OFL.txt`, from the
  project's tag v4.007; the release zip carries no licence file). The DIN 1451 standard itself is protected
  (Paragraph 5(3) UrhG), hence the separately licensed lookalike.
