# Trafikk Regular — source and permission

Aitor, Trafikk Regular (2021). Unmodified original file downloaded from
https://aitor.online/media/downloads/Trafikk-regular.ttf

Author/source: https://aitor.online/work/trafikkfont/

The author describes it as an open-source interpretation of the specifications
of Statens vegvesen, with some deliberately modified letters. The source page
expressly permits printing, selling and bundling. It is not presented as an
unchanged official government font. This permission is independent of the SIL
OFL licences of the other fonts in this directory.
