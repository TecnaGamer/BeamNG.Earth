**BeamNG.Earth: Australia test build.** This is a fork of BeamNG.Earth 1.8.2-beta with an Australian look: buildings for each state, vegetation from NVIS 7.0 (rainforest, eucalypt woodland, mallee and grassland, plus long dry grass in the dry season), AU road markings and signs, give way, signals, guide posts, R4-1 speed signs and Australian default speed limits. Outside Australia it is the same as upstream.

### New in au.2
- Payphones and post boxes from OpenStreetMap (`amenity=telephone` / `post_box`), placed on the footpath. They need the Gas stations setting on.
- T-junction chevron boards at rural T-intersections.
- No speed signs on roundabouts.

### How to try it
1. Close BeamNG.drive, and close the BeamNG.Earth window if it's open.
2. Download **`BeamNG.Earth-1.8.2-beta-AU.exe`** below and run it. Windows may say it's an unknown app; click More info, then Run anyway. It works the same way as the normal BeamNG.Earth exe: it installs its version of the mod over your current one, starts the world server and starts the game.
3. In Freeroam, pick **BeamNG.Earth** and go anywhere in Australia. Rockhampton, Yeppoon, Kuranda, Brisbane and Winton are good places to look.

The first visit to an area takes a little longer, because roads and trees are rebuilt with the AU rules.

### Going back to normal BeamNG.Earth
Run the official BeamNG.Earth exe again. It puts the upstream mod back. Your map cache is shared, so nothing is lost.
