# Offline signal context data

Rijkswaterstaat / NDW: WKD KOM_BORDEN, peildatum 7 October 2026.
https://downloads.rijkswaterstaatdata.nl/wkd/geogegevens/Geopackage/Komgrenzen/01-10-2026/

OpenStreetMap contributors: turn:lanes (source base timestamp 2026-11-06T21:32:19Z)
and 22,512 explicit traffic-signal nodes on motor-vehicle roads in the Netherlands.
Open Database Licence (ODbL): https://www.openstreetmap.org/copyright
Query and source hashes are recorded in context_provenance.json.

The original lane tags and source IDs remain in the derived spatial data pack.
Geometry is simplified by at most 1 metre and quantized at 0.5 Mercator metres.
The game performs local spatial matching; this is not a surveyed sign location or an NWB/Overture identity join.
