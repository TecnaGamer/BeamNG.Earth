# Wyoming and nationwide highway shields

See [Nationwide highway shields](nationwide-highway-shields.md) for current
architecture, coverage, licensing and limitations. Wyoming's horse-and-rider face
was the initial visual pilot; the shared registry now includes all 50 standard
state designs. Signs generate through normal road streaming. No manual regional
sign inventories are required. The historical Wyoming station sample is retained
only under tests/fixtures and is excluded from application packages.
