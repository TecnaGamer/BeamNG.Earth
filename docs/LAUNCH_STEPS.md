## How to launch BeamNG.Earth

BeamNG.Earth is **not** a normal mod: it needs its own app running next to the game, because the app builds the real
world while you drive. **Don't** put a zip into your `mods` folder, and **don't** start the game from Steam: start the
app instead, and it starts the game for you.

1. **Start Steam** (it only needs to be running; you don't press Play).
2. **Download** the app for your system from the Assets list below:
   - **Windows:** `BeamNG.Earth-{version}.exe`
   - **Linux / Steam Deck:** `BeamNG.Earth-{version}-x86_64.AppImage`. Make it executable first (right-click >
     Properties > "Allow executing", or `chmod +x BeamNG.Earth-{version}-x86_64.AppImage`).
3. **Run the file you downloaded** (double-click it).
   - Windows may say "Windows protected your PC": click **More info**, then **Run anyway**.
   - A console window opens. It installs the mod into the game, starts the world server, then starts BeamNG.drive.
     **Keep this window open while you play.** Closing the game stops it.
   - On Windows, BeamNG's usual launch options window appears: pick your renderer and press **Play**.
4. **In the game:** main menu > **Freeroam** > pick the **BeamNG.Earth** level.
5. **Pick a place:** press **M** for the world map. Search a town or address, **right-click** to teleport there,
   **left-click** to set a GPS route. The first visit to a place takes a little while to download.

**Multiplayer (BeamMP):** start the BeamNG.Earth app the same way (it starts BeamMP with the game; the first time it
offers to install BeamMP's launcher). In the game: main menu > **More** > **BeamMP**, log in, then pick the
**BeamNG.Earth** category in the server browser. Every player needs the app running, and the same version as the
server.

**Updating:** the game tells you when a new version is out. Click **Update now** in that notice, and the next time
you start the app it runs the new version. Or download the new file from the releases page and run it the same way.

**Need help?** Ask in the TGForever Discord: [discord.gg/tgf](https://discord.gg/tgf). More detail is in the
[README](https://github.com/TecnaGamer/BeamNG.Earth#install-and-play).
